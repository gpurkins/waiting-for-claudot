# Waiting for Claudot

A tragicomedy in two sounds.

## Act I

DEVELOPER sits at terminal. Waiting.

```bash
./enable-autopilot-sounds.sh
```

*A sound. The machine thinks. Or pretends to.*

## Act II

Nothing happens. Nobody comes. Nobody goes. It's awful.

*Another sound. The machine stops.*

DEVELOPER: It worked?

CLAUDE: Perhaps.

DEVELOPER: Let's go.

*They do not move.*

## Requirements

- macOS
- jq
- The will to continue

## Disable

```bash
./disable-autopilot-sounds.sh
```

*Silence returns. Was it ever otherwise?*
